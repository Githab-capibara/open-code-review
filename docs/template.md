# Documentation Structure Template

This file defines the expected structure for top-level documentation entries
that do not fit a single subdirectory template. Use it as a reference when
creating new top-level documentation guides or when adding a new section to
the root of `docs/`.

## Title

**Status:** Draft | Active | Deprecated
**Date:** YYYY-MM-DD
**Owner:** GitHub handle of the maintainer
**Related:** links to related ADRs, subdirectory overviews, or upstream docs

## Purpose

What this document covers and why it exists. One or two short paragraphs.

## Contents

A bullet list of the major sections this guide covers.

## References

- Links to related documentation, source files, or external specifications.
