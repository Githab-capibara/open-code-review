## Format

Each design document follows the research-note format:

1. **Status** — `Research note` or `Proposed` / `Accepted`.
2. **Deciders** — GitHub handles.
3. **Researcher** — who did the research.
4. **Purpose** — why this research exists.
5. **Feeds into** — which ADR or architecture document it informs.

Use [`template.md`](template.md) as the starting point.
